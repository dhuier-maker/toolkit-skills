# 风格详解

## 科技蓝 (tech-blue)

**适用场景**：BI大屏、数据可视化、科技主题

**色彩方案**：
```css
--primary: #0d1b2a;     /* 深蓝黑 - 主背景 */
--secondary: #1b2838;   /* 次背景 */
--accent: #00d4ff;      /* 电光青 - 强调色 */
--accent-glow: rgba(0, 212, 255, 0.5);  /* 发光效果 */
--gold: #ffd700;        /* 金色 - 点缀 */
--text: #ffffff;        /* 文字色 */
--text-muted: #87ceeb;  /* 次要文字 */
```

**视觉效果**：
- 深蓝渐变背景
- 网格线装饰
- 光点/粒子漂浮
- 边缘发光效果

**CSS 示例**：
```css
background: linear-gradient(135deg, #0d1b2a 0%, #1b2838 50%, #0d1b2a 100%);
```

## 商务 (business)

**适用场景**：企业PPT、商务报告、正式场合

**色彩方案**：
```css
--primary: #1a1a2e;     /* 深灰蓝 */
--secondary: #16213e;   /* 次背景 */
--accent: #4a90d9;      /* 商务蓝 */
--highlight: #e94560;   /* 强调红 */
--text: #ffffff;
--text-muted: #a0a0a0;
```

**视觉效果**：
- 稳重渐变
- 几何图形装饰
- 简洁线条
- 专业感

---

## 简约 (minimal)

**适用场景**：设计类PPT、文艺博客、极简风格

**色彩方案**：
```css
--primary: #f5f5f5;     /* 浅灰背景 */
--secondary: #ffffff;   /* 白色 */
--accent: #333333;      /* 深灰 */
--highlight: #0066cc;   /* 蓝色强调 */
--text: #333333;
```

**视觉效果**：
- 大面积留白
- 简单几何线条
- 单色或双色
- 极简主义

---

## 渐变 (gradient)

**适用场景**：创意PPT、艺术封面、时尚主题

**色彩方案**：
```css
/* 紫蓝渐变 */
--start: #667eea;
--mid: #764ba2;
--end: #f093fb;

/* 或橙红渐变 */
--start: #f093fb;
--end: #f5576c;
```

**视觉效果**：
- 流动渐变
- 柔和光晕
- 多色过渡
- 梦幻感

---

## 暗黑 (dark)

**适用场景**：游戏主题、科技发布会、酷炫风格

**色彩方案**：
```css
--primary: #0a0a0a;     /* 纯黑 */
--secondary: #1a1a1a;   /* 深灰 */
--accent: #00ff88;      /* 霓虹绿 */
--accent-alt: #ff0080;  /* 霓虹粉 */
--text: #ffffff;
```

**视觉效果**：
- 暗黑背景
- 霓虹光效
- 赛博朋克元素
- 高对比度

---

## 温暖 (warm)

**适用场景**：生活博客、美食主题、温馨风格

**色彩方案**：
```css
--primary: #fff5e6;     /* 米白 */
--secondary: #ffe4c4;   /* 浅橙 */
--accent: #ff8c00;      /* 橙色 */
--highlight: #d2691e;   /* 棕色 */
--text: #4a3728;
```

**视觉效果**：
- 暖色调
- 柔和渐变
- 温馨感

---

## 冷静 (cool)

**适用场景**：科技博客、数据分析、专业报告

**色彩方案**：
```css
--primary: #e8f4f8;     /* 浅蓝灰 */
--secondary: #d0e8f2;   /* 淡蓝 */
--accent: #2196f3;      /* 蓝色 */
--highlight: #0d47a1;   /* 深蓝 */
--text: #1a237e;
```

**视觉效果**：
- 冷色调
- 清爽感
- 专业感
