# 文本组件模板

适用于大屏标题、日期时间显示、跑马灯滚动文本等纯展示类组件。

## 支持的模板

| 模板文件 | 说明 |
|----------|------|
| `title.md` | 大屏标题，支持字体/颜色/阴影/背景配置 |
| `datetime.md` | 日期时间组件，支持日期/时间/星期显示，实时更新 |
| `marquee.md` | 跑马灯滚动文本，支持方向/速度/悬停暂停 |

## 完整参考

所有文本组件完整代码请参考 `references/component-templates.md` 第八节。

## 通用特点

- 纯 CSS/Vue 实现，不依赖 ECharts
- 所有用户可见文本使用 i18n 国际化
- Props 遵循完整元数据规范
- 支持 configurationTemplate 可视化配置
