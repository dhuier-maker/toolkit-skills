# Web 前端体验检查表

按任务需要选择检查项，不要求每次全部展开。

## 信息与任务

- 首屏是否能说明页面目的和主要操作。
- 重要数据、操作和风险是否具有清晰优先级。
- 空态、加载态、错误态和无权限状态是否完整。

## 交互

- 可点击区域、禁用态、焦点态和提交反馈是否明确。
- 异步操作是否防重复、可取消或提供进度。
- 弹窗、抽屉、分页、筛选和返回行为是否一致。

## 可访问性

- 图片和图标是否有适当的替代信息。
- 键盘能否到达核心操作，焦点顺序是否合理。
- 文本、图表和状态色是否具备足够对比度，信息是否不只依赖颜色。

## 响应式与大屏

- 普通页面检查断点、溢出、长文本和缩放。
- 固定比例大屏检查设计基准、窗口缩放、图表 resize、定时器和监听器清理。
- 检查关键内容在非标准宽高比下是否仍可读。

## 输出

每个问题包含证据位置、用户影响、优先级、建议方案和验收方法。未运行浏览器时注明“静态审查”。
