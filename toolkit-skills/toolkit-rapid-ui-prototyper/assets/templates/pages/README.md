# Pages Templates Overview

页面模板说明。本目录下的模板提供完整的页面 HTML，可直接使用或组合修改。每个页面包含完整的样式和 JavaScript 交互。

> **约定**：所有页面遵循 SKILL.md 中的主题系统约定。颜色使用 CSS 变量，明暗切换使用 `body.light-mode`。

---

## 页面文件一览

| 文件 | 场景 | 包含布局 | 核心交互 |
|------|------|---------|---------|
| `login.md` | 登录/注册 | 居中卡片式 | 表单验证、密码显示切换、主题切换 |
| `admin-dashboard.md` | 管理后台首页 | 侧边栏（引用） | 统计卡片、ECharts 图表、数据表格、主题切换 |
| `form-page.md` | 数据录入/编辑 | 顶部导航（引用） | 多字段表单验证、提交处理 |
| `list-detail.md` | 数据管理 | 侧边栏（引用） | 搜索筛选、表格展示、分页、详情弹窗 |

---

## 使用方式

### 独立页面

直接复制整个 HTML 文件内容，保存为 `*.html` 并在浏览器中打开。

### 组合到布局中

页面模板中的内容区可以提取出来，填充到布局模板（`../layouts/`）的内容插槽中：

```html
<!-- layouts/sidebar-nav.md 中的内容区 -->
<div class="page-content">
  <!-- 复制 admin-dashboard.md 或 list-detail.md 的内容到这里 -->
</div>
```

### 主题变量

每个页面模板都包含了完整的 `:root` 变量定义。在多视图场景下，可以将变量定义提取到公共的 `themes/` 模板中。
