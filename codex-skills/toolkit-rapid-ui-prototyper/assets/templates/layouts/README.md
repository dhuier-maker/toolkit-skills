# Layout Patterns Overview

布局模式模板说明。本目录下的模板提供完整的页面骨架结构（HTML），包含导航栏、内容区、页脚等。选择布局后，在其中填充组件和内容即可。

> **约定**：布局中的颜色全部使用 CSS 变量（`var(--admin-*)` / `var(--brand-*)`），禁止硬编码。主题切换使用 `body.light-mode`。

---

## 布局文件一览

| 文件 | 适用场景 | 响应式策略 |
|------|----------|-----------|
| `sidebar-nav.md` | 后台管理、仪表盘、数据分析 | 桌面：侧栏展开；平板：折叠图标；手机：抽屉式 |
| `top-nav.md` | 官网、SaaS 应用、文档站、门户 | 桌面：水平导航；手机：汉堡菜单折叠 |
| `mobile-bottom-tab.md` | 移动端 App、H5 页面 | 移动端专用；固定底部 Tab，顶部导航栏 |

## 布局模式选择指南

### 侧边栏导航（sidebar-nav）

```
┌─────────┬──────────────────────────────┐
│         │  Header（顶部操作栏）          │
│ Sidebar ├──────────────────────────────┤
│ 导航    │  Content（主要内容区）         │
│ 菜单    │                              │
│         │                              │
└─────────┴──────────────────────────────┘
```

**适合**：菜单数量多（>5项）、需要深度导航、数据密集型的后台

### 顶部导航（top-nav）

```
┌────────────────────────────────────────┐
│  Logo    导航1  导航2  导航3    头像    │
├────────────────────────────────────────┤
│  Content（主要内容区）                  │
│                                        │
└────────────────────────────────────────┘
```

**适合**：菜单数量少（<8项）、内容为主的网站、SaaS 应用

### 移动端底部 Tab（mobile-bottom-tab）

```
┌────────────────────────────────────────┐
│  Header（顶部标题栏 + 返回）            │
├────────────────────────────────────────┤
│  Content（可滚动内容区）                │
│                                        │
├────────────────────────────────────────┤
│  Tab1  Tab2  Tab3  Tab4（底部导航）     │
└────────────────────────────────────────┘
```

**适合**：移动端 H5、App 风格页面、底部 3-5 个主 Tab

## 使用方式

1. 复制对应布局模板的完整 HTML 到页面
2. 在 `<style>` 中引入对应的主题变量（参考 `themes/` 目录）
3. 在内容区填充组件（参考 `components/` 目录）
4. 根据需求调整侧栏菜单项、导航链接、Tab 图标等

---

## 多布局组合

同一个页面中，管理后台使用侧边栏布局，BI 大屏使用顶部导航布局：

```html
<body>
  <!-- 管理后台视图 - 侧边栏布局 -->
  <div id="view-admin" class="sidebar-layout">
    <!-- sidebar-nav.md 内容 -->
  </div>

  <!-- BI 大屏视图 - 顶部导航布局 -->
  <div id="view-bi" class="topnav-layout" style="display: none;">
    <!-- top-nav.md 内容（使用 bi-* 变量） -->
  </div>
</body>
```
