# 布局模板

> BI 大屏的布局结构模板，提供三栏布局和多TAB切换布局两种模式。

## 三栏布局

适用于大多数 BI 大屏场景，结构固定为：

```
┌─────────────────────────────────────────────────────────────┐
│                      顶部标题栏                              │
├──────────────┬─────────────────────────────┬────────────────┤
│              │                             │                │
│   左侧面板    │         中间区域             │    右侧面板     │
│   (320px)    │    (地图/图表/3D场景)        │    (320px)     │
│              │                             │                │
└──────────────┴─────────────────────────────┴────────────────┘
```

详见 [three-column.md](three-column.md)

## 多TAB切换布局

适用于智慧乡村、智慧街道等需要多个TAB视图切换的场景。

```
┌─────────────────────────────────────────────────────────────┐
│                      顶部标题栏                              │
├──────────────┬─────────────────────────────┬────────────────┤
│              │                             │                │
│   左侧面板    │         中间区域             │    右侧面板     │
│   (可滚动)    │    (地图/航拍/3D场景)        │    (可滚动)     │
│              │                             │                │
├──────────────┴─────────────────────────────┴────────────────┤
│   [基层治理]  [智慧党建]  [智慧养老]  [产业振兴]              │
│                    底部导航栏 (胶囊按钮)                      │
└─────────────────────────────────────────────────────────────┘
```

详见 [multi-tab.md](multi-tab.md)

## 3D数字孪生布局

适用于智慧城市、数字孪生等需要 3D 城市场景的大屏，中心区域为 Three.js 3D 城市模型：

```
┌─────────────────────────────────────────────────────────────┐
│                      顶部标题栏                              │
├──────────────┬─────────────────────────────┬────────────────┤
│              │                             │                │
│   左侧面板    │      3D 城市场景            │    右侧面板     │
│   (320px)    │   (Three.js City3D)         │    (320px)     │
│              │   · 旋转/缩放交互            │                │
│   数据概览    │   · 建筑点击→信息弹窗        │    统计图表     │
│   告警列表    │   · 悬浮高亮效果            │    排行榜       │
│              │   · CSS2D 浮动标签          │                │
│              │   · 数据叠加面板            │                │
└──────────────┴─────────────────────────────┴────────────────┘
```

详见 [digital-twin.md](digital-twin.md)

## 网络关系布局

适用于组织架构、设备拓扑、知识图谱等关系型数据的大屏，中心区域为径向网络关系图：

```
┌─────────────────────────────────────────────────────────────┐
│                      顶部标题栏                              │
├──────────────┬─────────────────────────────┬────────────────┤
│              │                             │                │
│   左侧面板    │      径向网络关系图          │    右侧面板     │
│   (320px)    │   (SVG / Canvas)            │    (320px)     │
│              │                             │                │
│   节点统计    │      · 中心节点             │    详情面板     │
│   分类列表    │      · 子节点径向排列        │    关联信息     │
│              │      · 连接线动画            │                │
│              │      · 节点点击→右侧详情      │                │
└──────────────┴─────────────────────────────┴────────────────┘
```

详见 [network-relation.md](network-relation.md)

## 3D投影中心布局

适用于数字人、产品展示、人物档案等需要 3D 全息投影效果的大屏，中心为全息投影，底部为卡片网格：

```
┌─────────────────────────────────────────────────────────────┐
│                      顶部标题栏                              │
├──────────────┬─────────────────────────────┬────────────────┤
│              │                             │                │
│   左侧面板    │      3D 全息投影区域        │    右侧面板     │
│   (320px)    │   (HologramContainer)       │    (320px)     │
│              │                             │                │
│   基础信息    │      · 全息模型展示         │    属性面板     │
│   状态指标    │      · 圆形光晕底座         │    技能/标签    │
│              │      · 自动旋转             │                │
│              ├─────────────────────────────┤                │
│              │      底部卡片网格            │                │
│              │   (2x3 / 3x3 数据卡片)      │                │
└──────────────┴─────────────────────────────┴────────────────┘
```

详见 [hologram-center.md](hologram-center.md)

## 顶部卡片+网格布局

适用于多指标监控、KPI仪表盘场景，顶部KPI卡片行+下方图表网格：

```
┌─────────────────────────────────────────────────────────────┐
│                      顶部标题栏                              │
├─────────────────────────────────────────────────────────────┤
│  [KPI卡片1]  [KPI卡片2]  [KPI卡片3]  [KPI卡片4]             │
├─────────────────────┬───────────────────────────────────────┤
│                     │                                       │
│    图表1            │          图表2                         │
│                     │                                       │
├─────────────────────┼───────────────────────────────────────┤
│                     │                                       │
│    图表3            │          图表4                         │
│                     │                                       │
└─────────────────────┴───────────────────────────────────────┘
```

详见 [top-cards-grid.md](top-cards-grid.md)
