# 失败重试机制

当某个 Skill 执行失败时，自动进行重试：

## 重试策略

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `maxRetries` | 3 | 最大重试次数 |
| `retryDelay` | 5000ms | 重试间隔 |
| `exponentialBackoff` | true | 是否启用指数退避 |

## 重试流程

```
Skill 执行失败
    ↓
检查重试次数 < maxRetries
    ↓ 是
等待 retryDelay（指数退避：5s → 10s → 20s）
    ↓
重新执行 Skill
    ↓
仍失败 → 记录错误，询问用户
```

## 重试示例

```
═══════════════════════════════════════════════════════════
📋 阶段 7: 测试验证 (toolkit-qa-tester)
═══════════════════════════════════════════════════════════

🔍 已调用 toolkit-qa-tester
❌ 执行失败：MCP 连接超时

🔄 重试策略：
├── 当前重试：1/3
├── 等待时间：5秒
└── 下次重试：2026-04-21 15:00:05

🔄 第 1 次重试...
❌ 仍然失败：MCP 连接超时

🔄 重试策略：
├── 当前重试：2/3
├── 等待时间：10秒
└── 下次重试：2026-04-21 15:00:15

🔄 第 2 次重试...
✅ 重试成功

📊 测试结果：
├── Critical Bug: 0
├── Warning Bug: 1
└── Info: 0
```

## 重试失败处理

当达到最大重试次数仍失败时：

```
❌ Skill 执行失败，已达到最大重试次数 (3/3)

📋 失败信息：
├── Skill: toolkit-qa-tester
├── 错误: MCP 连接超时
├── 重试次数: 3
└── 最后重试时间: 2026-04-21 15:00:30

💬 请选择处理方式：
1. 手动修复问题后继续
2. 跳过当前阶段
3. 回退到上一阶段
4. 终止工作流
```
