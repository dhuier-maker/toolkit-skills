# PPT 风格模板库

10 套可直接引用的风格模板，每套含：配色、字体、背景、布局规则、grammar 文本示例。

---

## 模板 1：Tech Blue（科技蓝）

**适用场景**：数字化产品发布、AI/科技公司介绍、技术平台演示

**配色**：
- Primary: `#0d1b2a`（深海蓝背景）
- Accent: `#00d4ff`（科技蓝高亮）
- Secondary: `#1a3a5c`（中蓝渐变）
- Text: `#ffffff`（白色文字）
- Gold: `#ffd700`（数据金强调）

**字体**：
- 主标题：Noto Serif SC 900，80-120pt
- 副标题：Noto Serif SC 400，36-48pt
- 正文：Noto Serif SC 400，24-32pt

**背景**：
- 深蓝渐变 `#0d1b2a → #1a3a5c`
- 叠加光点粒子效果（opacity 0.3）
- 网格线元素（opacity 0.1）

**Grammar 示例**：
```markdown
## Tech Blue Grammar
- Background: dark blue gradient #0d1b2a → #1a3a5c with floating light particles
- Primary accent: #00d4ff (cyan glow)
- Secondary accent: #ffd700 (gold for data highlights)
- Typography: Noto Serif SC, bold titles, clean sans for body
- Layout: title top-center, content middle-lower, right reserved for product visual
- Style: futuristic, data-driven, cinematic rendering, premium tech aesthetic
- No clutter, generous whitespace, strong visual hierarchy
```

## 模板 2：Dark Aurora（暗黑极光）

**适用场景**：高端品牌发布、创意机构、产品愿景演示

**配色**：
- Background: `#0a0a0a`（纯黑）
- Accent 1: `#ff0080`（霓虹粉）
- Accent 2: `#7b2fff`（电紫）
- Accent 3: `#00ffcc`（青绿）
- Text: `#f0f0f0`（柔白）

**字体**：
- 主标题：Source Serif Pro 900，90-140pt
- 副标题：Source Serif Pro 400，32-40pt
- 正文：Inter 400，20-28pt

**背景**：
- 纯黑底 + 渐变色块（粉/紫/青绿三色流动）
- 或单色极光光晕效果

**Grammar 示例**：
```markdown
## Dark Aurora Grammar
- Background: pure black #0a0a0a with flowing gradient orbs (pink #ff0080 / purple #7b2fff / cyan #00ffcc)
- Typography: Source Serif Pro for display, Inter for body
- Layout: dramatic large type, asymmetric composition, generous negative space
- Style: high-contrast, cinematic, premium, editorial-noir aesthetic
- Mood: bold, creative, boundary-pushing
```

## 模板 5：Editorial Mono（编辑单色）

- 纯白底

```markdown
## Editorial Mono Grammar
```

## 模板 8：Riso Print（ riso印刷风）

**适用场景**：创意工作坊、艺术活动、独立品牌、实验性内容

**配色**：
- Background: `#f5f0e8`（米黄纸）
- Spot 1: `#ff6b6b`（Riso 红）
- Spot 2: `#4ecdc4`（Riso 青）
- Spot 3: `#ffe66d`（Riso 黄）
- Text: `#1a1a1a`（墨黑）

**字体**：
- 主标题：Archivo Black 900，70-100pt
- 副标题：Archivo 500，24-36pt
- 正文：IBM Plex Mono 400，16-22pt

**背景**：
- 米黄纸 `#f5f0e8`
- Riso 色块（不透明 80%，带轻微错位边缘）
- 复古印刷质感

**Grammar 示例**：
```markdown
## Riso Print Grammar
- Background: warm paper #f5f0e8 with subtle grain
- Colors: Riso spot colors — red #ff6b6b, cyan #4ecdc4, yellow #ffe66d
- Overprints: slight misregistration (2-3px offset) between spot colors for riso effect
- Typography: Archivo Black for display, IBM Plex Mono for body
- Layout: bold, editorial-poster style, asymmetric grids
- Style: risograph print aesthetic, DIY culture, underground, vibrant
```

## 模板 9：Y2K Chrome（Y2K 金属质感）

**适用场景**：科技复古、怀旧活动、90-00年代主题、创意营销

**配色**：
- Background: `#0a0a2e`（深蓝黑）
- Chrome: `linear-gradient(135deg, #667eea, #764ba2, #f093fb, #667eea)`（金属渐变）
- Accent: `#00d4ff`（青色高光）
- Text: `#ffffff`（白色）

**字体**：
- 主标题：Azeret Mono 900，70-100pt
- 副标题：Azeret Mono 500，24-36pt
- 正文：Azeret Mono 400，16-22pt

**背景**：
- 深蓝黑底 `#0a0a2e`
- 金属质感文字（渐变填充）
- 像素/网格装饰元素

**Grammar 示例**：
```markdown
## Y2K Chrome Grammar
- Background: deep blue-black #0a0a2e
- Chrome effect: metallic gradient text (135deg linear-gradient through purple, pink, cyan)
- Accent: bright cyan #00d4ff for glows and highlights
- Typography: Azeret Mono (geometric mono), bold chrome treatment for titles
- Decorative: pixel grids, circuit-like lines, starburst elements
- Style: Y2K aesthetic, chrome typography, retro-futuristic, nostalgic yet fresh
```

## 模板 10：Swiss Grid（瑞士网格）

**适用场景**：建筑设计、工业产品、数据报告、国际化企业

**配色**：
- Background: `#ffffff`（纯白）
- Primary: `#e11d48`（瑞士红）
- Secondary: `#1e293b`（深灰蓝）
- Tertiary: `#64748b`（中灰）
- Line: `#e2e8f0`（极浅灰线）

**字体**：
- 主标题：Helvetica Neue 700，60-90pt
- 副标题：Helvetica Neue 400，24-32pt
- 正文：Helvetica Neue 400，16-22pt
- Data：Roboto Mono 500，20-28pt

**背景**：
- 纯白底
- 红色强调线（4pt）
- 严格网格系统（12列）

**Grammar 示例**：
```markdown
## Swiss Grid Grammar
- Background: pure white #ffffff with strict 12-column grid
- Primary accent: Swiss red #e11d48 for key lines and highlights
- Typography: Helvetica Neue (or alternatives), rigorous grid alignment
- Layout: asymmetric grid, strong left alignment, clear data hierarchy
- Style: Swiss International Style, typographic precision, data-forward, international
- Key feature: red accent line (4pt) always aligns to grid
```
